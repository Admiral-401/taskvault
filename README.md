# 🗂️ TaskVault – Smart To-Do App (Vite + Vanilla JavaScript)

TaskVault is a modern, fast, and minimal to-do application built using **Vanilla JavaScript** and **Vite**.  
It helps users organize daily tasks efficiently with features like adding, completing, deleting, filtering, and persistent storage using LocalStorage.

## ✨ Features

- ➕ Add new tasks instantly
- ✔ Mark tasks as complete/incomplete
- ❌ Delete tasks safely
- ⚠ Prevent deletion of incomplete tasks (warning modal)
- 🔍 Filter tasks (All / Completed / Pending)
- 💾 Persistent storage using LocalStorage
- ⌨ Add tasks using Enter key
- 🔄 Dynamic rendering using event delegation
- ⚡ Fast build system powered by Vite
